개인정보처리방침

시행일·최종 수정일: 2026년 7월 22일
J-news는 서비스 제공에 필요한 정보만 처리합니다. Google 로그인은 선택 사항이며, 로그인 없이도 뉴스 브리핑을 이용할 수 있습니다.

1. 처리하는 정보

구분정보목적
선택적 Google 로그인 Firebase 사용자 ID, 이메일, 이름, 프로필 정보 Google 로그인, 계정 상태 유지
AI 질문 사용자 질문, 해당 대화 기록, 보고 있던 뉴스 제목·요약·용어, 로그인 시 Firebase 사용자 ID 문맥에 맞는 AI 답변 제공, 일일 사용량 제한
AI 답변 신고 신고 사유, 직전 질문, 신고한 AI 답변, 뉴스 제목 부정확하거나 부적절한 생성 콘텐츠 검토·개선
Firebase Analytics 앱 실행, 화면·버튼 이용, 뉴스 열람·완독, 오류·진단 정보, 앱 인스턴스·기기 식별 정보, 로그인 시 Firebase 사용자 ID 이용 흐름 분석, 오류 확인, 서비스 개선
Google Mobile Ads IP 주소, 광고 상호작용, 진단 정보, 기기 또는 광고 식별자 광고 제공, 성과 측정, 부정 사용 방지
서버 보안 IP 주소, 요청 시각 짧은 시간 내 과도한 요청 차단. IP는 메모리에서 일시 처리하며 J-news 데이터베이스에 저장하지 않음
기기 저장 정보 북마크, 뉴스 캐시, 퀴즈·복습 기록, 온보딩·알림·테마 설정 오프라인 열람, 학습 기록, 사용자 설정 유지

2. 처리 방법과 제3자 서비스

  • Google Firebase Authentication: 선택적 Google 로그인
  • Google Firebase Analytics: 앱 이용 분석과 오류 확인
  • Google Mobile Ads: 광고 제공과 측정
  • Google Gemini API: AI 질문, 대화 기록과 뉴스 문맥을 이용한 답변 생성
  • Vercel 및 데이터베이스 호스팅 사업자: API 운영과 신고 데이터 보관

위 사업자는 서비스 제공에 필요한 범위에서 정보를 처리할 수 있습니다. Google 서비스의 처리 기준은 Google 개인정보처리방침, Vercel의 기준은 Vercel Privacy Policy에서 확인할 수 있습니다.

모든 앱·서버 통신은 HTTPS로 암호화합니다. J-news 서버는 AI 질문과 대화 본문을 데이터베이스에 저장하지 않습니다. 일일 사용량 확인용 UID 또는 IP는 원문을 저장하지 않고 날짜별 HMAC 값으로 바꾸어 처리합니다.

3. 보유 기간

  • Google 로그인 계정 정보: 사용자가 계정을 삭제할 때까지
  • 채팅 사용량 가명 식별자: 생성 후 최대 2일
  • AI 답변 신고: 접수 후 최대 90일
  • Firebase Analytics 이벤트 데이터: Firebase 설정에 따른 기간 동안, 최대 14개월 이내
  • 기기 저장 정보: 사용자가 앱 데이터 또는 계정을 삭제할 때까지

법령상 보존 의무가 있거나 분쟁 처리가 필요한 경우에만 필요한 범위에서 별도로 보관할 수 있습니다.

5. 삭제와 이용자 권리

  • 로그인 계정 삭제: 앱의 설정 → 계정 및 데이터 삭제
  • 로그인 없이 저장된 기기 데이터 삭제: 기기 설정 → 앱 → J-news → 저장공간 → 데이터 삭제
  • 앱에 접근할 수 없는 경우: 계정 삭제 안내 페이지 또는 이메일 요청

계정 삭제 시 Firebase 로그인 계정과 J-news의 기기 저장 정보를 삭제합니다. 계정과 연결하지 않고 익명으로 접수한 AI 신고는 계정 삭제 대상과 연결할 수 없으며 90일 안에 자동 삭제됩니다.

6. 아동 보호

현재 공개 버전은 만 14세 미만 아동을 주 이용자로 설계하지 않았습니다. 만 14세 미만을 대상으로 서비스를 변경하기 전에는 법정대리인 동의, 연령 확인, 아동 대상 광고·데이터 처리 기준을 별도로 적용하고 본 방침을 갱신합니다.

7. 방침 변경

서비스 또는 법령이 바뀌면 본 페이지를 수정합니다. 처리 항목이나 목적이 중요하게 바뀌는 경우 앱 내 공지 등으로 알립니다.
